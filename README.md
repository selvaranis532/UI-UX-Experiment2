# UI-UX-Experiment2

## Aim:

To design a brand logo and create responsive mobile and web layouts for a digital product by applying UI/UX principles, Gestalt principles, usability guidelines, and branding techniques to achieve a user-friendly and visually consistent interface.

## Algorithm:
Step 1: Select a digital product such as a food delivery app, travel app, or e-commerce website and understand its purpose, target audience, and user flow.

Step 2: Apply Gestalt principles such as proximity, similarity, continuity, closure, and figure-ground to improve visual hierarchy and layout organization.

Step 3: Design UI layouts for mobile and web using tools like Figma or Adobe XD by creating wireframes that include navigation bars, buttons, input fields, cards, and other UI components following responsive design principles.

Step 4: Integrate interaction and usability features such as hover effects, transitions, feedback messages, and ensure consistency, accessibility, and affordance in the design.

Step 5: Design a brand logo using Canva that represents the product identity with suitable colors, fonts, and scalable design, and embed it into the UI layouts.

Step 6: Review the complete design by checking alignment, spacing, contrast, and visual flow, then export the final layouts and document the design process.
